# 架构

```text
浏览器（初始化、登录、单路径工作台）
        │ 会话 + CSRF + JSON/HTTP
应用服务（Python 标准库，默认仅本机）
        ├── 文档切分与中文检索
        ├── Ollama 本地模型 / 证据抽取降级
        ├── 引用校验与报告
        ├── 人工审批
        └── 审计日志
          │                 │
        SQLite         Ollama 本地 API
```

核心不绑定开发机、固定工作站配置、GPU 品牌、模型品牌、向量库或操作系统。Ollama + Qwen 是当前可运行的参考适配器，不是产品边界。扩展分三层：

- 文档适配器：PDF、OFD、Office、PaddleOCR。
- 模型适配器：Xinference、vLLM、Ollama 或其他 OpenAI 兼容本地端点。
- 工具适配器：Skill 描述工作方法；MCP 暴露标准化工具。所有写操作必须在 UI 中预览并人工确认。

核心保留零依赖证据抽取，使没有 GPU 或模型的机器仍能跑通流程；Docker 发行版同时部署 Ollama 和固定版本 Qwen 模型。后续可替换检索和生成引擎，但身份、审批、证据与审计协议保持稳定。
