# Alpha 安全边界

| 能力 | 当前状态 | 生产要求 |
|---|---|---|
| 网络 | 默认 `127.0.0.1` | 内网分区、TLS、访问控制 |
| 身份 | 本机单管理员、会话、CSRF、登录限速 | SSO、RBAC、最小权限 |
| 数据 | 本地 SQLite | 分类分级、加密、备份、销毁 |
| 审计 | 本地追加记录 | 集中、防篡改、留存策略 |
| 模型 | Ollama 固定清单；仅本机/同栈端点；失败降级；回答引用校验 | 权重来源审查、内容安全、专项评测 |
| 文档 | 纯文本 | 恶意文件检测、OCR 沙箱、病毒扫描 |

禁止在 Alpha 导入国家秘密、工作秘密、未脱敏个人信息或生产凭据。
