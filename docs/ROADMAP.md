# 路线图

## v0.1 Alpha（已完成）

- 文本材料、证据检索、引用问答、简报、审批、审计。
- 单机单用户，仅公开/合成/脱敏数据。

## v0.2 可部署 Alpha（当前）

- Windows/Linux/macOS 可执行程序和 Docker 一键安装。
- 固定版本本地模型、硬件诊断、下载进度和证据校验。
- 首次管理员、会话、CSRF、登录限速和身份绑定审批。
- 可复现离线介质包、SHA-256、发行 SPDX SBOM。

## v0.3 部门试点

- PDF/OFD/Office 与 PaddleOCR。
- 用户、部门、角色、知识空间和分级授权。
- Xinference/RAGFlow 可选适配器，国产模型离线包。
- SM2/SM3/SM4 密码组件适配点和审计导出。

## v0.4 生产候选

- 高可用、备份恢复、日志防篡改、供应链 SBOM。
- 国产 CPU/GPU/操作系统/数据库兼容性矩阵。
- 电子签章、统一身份、信创环境验收脚本。
- 由实际部署单位完成等保、密评和数据合规评估。
